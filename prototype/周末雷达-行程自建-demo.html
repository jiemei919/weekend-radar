行程自建 + 数据同步 · demo

内部实现细节你看不到；这里只展示"你以后怎么用"。

1 在「🗺️ 旅行路线」点「＋ 新建行程」

🗺️ 旅行路线 →

按钮在路线库列表顶部（和现有卡片同一风格，本周最热不动）。

2 填一张表单

名称、天数必填；天数决定生成几天空白卡。

3 自动生成空白每日卡，你边走边改

Day1 2026/10/1 · 待定
🚗 路线：（点编辑填写）
🏨 住宿：（待定）
🕐 时间 / ⚠️ 注意 / 💰 费用：编辑模式逐条加
Day2 2026/10/2 · 待定
🚗 路线：（点编辑填写）
Day3 2026/10/3 · 待定
🚗 路线：（点编辑填写）

生成的卡和成都那套一模一样，可 ✏️编辑、改时间/路线/住宿/注意事项、记费用。

4 数据存哪 · 无服务器方案

你的改动 → 浏览器本地(localStorage) radar-routes-v1 ↓ 点「保存并同步」 GitHub 仓库(data/*.json) ──commit──▶ GitHub Pages(托管, 永远在线) ↑ 任意设备打开即拉最新 ↓ 版本历史=commits, 可回滚 手机 / 电脑 看同一份 · 这部 Mac 关机也不影响
  • 没有服务器、没有数据库，JSON 文件就是"数据库"。
  • 每次保存 = 一次 Git 提交，改错了能找回历史。
  • 手机和电脑打开同一个网址，数据互通。
⚠️ 这部分需要你有一个 GitHub 账号（你已有），给我仓库写权限或生成一个 token（仅写权限，可撤销）。
为什么不用本机/Obsidian：本机方案这部 Mac 一关就断；Obsidian 是笔记工具、不能托管网页 app。GitHub 同时托管 app + 存数据，关机也能从手机开。
Obsidian 可选：若你想在 Obsidian 里也"读"到行程，我可额外同步成笔记（主存储仍是 GitHub）。

5 验收（做出来后你会看到）

✅ 点「＋新建行程」→ 填表 → 路线库出现新路线 + N 天空白卡
✅ 编辑填好内容，刷新后还在
✅（Git 配好后）点「保存并同步」→ 另一台设备打开能看到
✅ 成都等原有路线不会被误删
