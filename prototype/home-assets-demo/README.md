# Home Assets · 家庭物品管理 Demo

纯 HTML / CSS / JavaScript 的移动端交互原型，无需安装依赖。风格沿用洁梅认可的 `home-assets-demo`（手机壳容器、大圆角渐变卡、柔和蓝 #4967f2、emoji 图标、生活化文案）。

## 使用方式

直接双击 `index.html`，或用任意静态服务器打开当前目录。

## 底部导航（4 个 tab）

- **首页**：今日天气卡（接 Open-Meteo 番禺真实天气）+ 今日穿搭推荐占位（即将上线）+ 需要留意（家当补货提醒）+ 快捷操作（拍订单 / 拍包装 / 手动添加）
- **我的宝贝**：成员头像切换（我 / 儿子 / 奶奶 / 爷爷）；按人大类（衣物 / 护理 / 自定义，衣物护理固定不可删）；衣物下细分 季节→部位 三级联动；护理支持多瓶管理（开新瓶 / 这瓶用完了）
- **＋**：AI 智能录入（拍订单 / 拍包装 / 手动添加）
- **家当**：家庭共用物品，默认大类 食物 / 洗护 / 家电，可自定义大类小类；消耗品支持 开封一件 / 用完一件 / 补了一件 流转，总数 ≤1 自动提醒补货

## 验证

`node smoke-v3.js`（需 jsdom）→ 23/23 通过，覆盖框架、我的宝贝、家当流转、无运行时报错。

原型使用 hash 路由实现页面切换，底部导航与页面内按钮均可点击。
