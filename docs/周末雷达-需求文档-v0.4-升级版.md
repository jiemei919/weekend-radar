## 0. 一句话定位（相对 v0.3 的变化）

v0.3 是一个"**周末周边游**推荐工具"。洁梅把项目定位升级为：**专门讨论和保存旅行相关内容，按可用假期天数（含法定节假日 + 请假拼假）推荐全家 4 口的合适玩法，并持续学习口味**。本版在保留 v0.3 全部机制（搜罗/打分/反馈/推送/换一批）之上，新增三大块：**全家旅行画像约束、法定节假日日历、请假拼假 → 按天数玩法推荐**。

## 1. 全家旅行画像与宗旨（最高优先级约束，雪花给建议时必须遵守）

### 1.1 家庭成员
| 角色 | 出生年 | 备注 |
|---|---|---|
| 洁梅 | 1988 | 主决策 + 自驾司机（一般只有 1 个司机） |
| 先生 | — | 随行 |
| 2 位老人 | 1956（约 70 岁） | 体力有限，随行 |
| 铄铄 | 2016.9（约 9 岁） | 超级爱熊猫、也爱妈妈喜欢的地点 |

出行固定一家 4 口（洁梅+先生+2老人+铄铄），老人小孩必随行。

### 1.2 旅行宗旨（7 条硬性约束）
1. 行程紧凑合理，**不匆忙打卡式旅行**（时间留足，节奏稳）
2. 时间节奏量化：
   - 博物馆 / 艺术馆：单个展览游览 **2.5~3h**
   - 自然风光景区：优先坐电瓶车 / 摆渡车；景点内容想逛完，耗时≈**大众平均 ×1.2**；路上多花时间休息、拍照
3. base 广州；出省大多**自驾（多考虑租车）**；偏好自然风光
4. 住宿：当地中等偏上酒店；纯住酒店 / 泡温泉 / 玩酒店项目 / 长隆类（酒店待很久）→ **度假酒店或乐园酒店**
5. 旅行时间多为**中国节假日**（小孩上学尽量不请假，大人上班；请假优先只请下午）
6. 日常作息：**8 点左右起，9 点出发**；晚上可开车赶路，但**偏向高速 / 城市道路，避免盘山国道**
7. 小朋友超爱熊猫 → 有看熊猫胜地（如四川）或知名动物园有大熊猫，**要安排一次**

### 1.3 文化偏好（自然风光 + 知名博物馆）
例：陕西博物馆、湖南博物馆（辛追夫人）、香港美术馆（莫奈 2 张）、三大石窟、三星堆。给出省行程建议时，若目的地有顶级博物馆 / 特别文物展，应主动纳入。

### 1.4 高海拔三原则（因老人小孩）
- ⭐ 海拔 > 4200m 且需长时间停留 / 徒步 → **原则上放弃**
- ⭐ 需骑马 / 越野车 / 长时间徒步才能到达 → **原则上放弃**
- ⭐ 能开车直达或观光车到达、老人孩子轻松欣赏核心景观 → **优先保留**

## 2. 法定节假日日历（新增核心机制）

### 2.1 数据文件
- 源数据：`data/holidays.json`，结构见下
- 前端镜像：`app/holidays.js`（`window.HOLIDAYS = {...}`，与 json 同步，供桌面工具离线读取）
- 维护：**每年 11 月左右国务院发布次年安排后，须更新本文件并核对调休补班日（workdays）**。2026 已官方确认；2027 按农历推算 + 调休原则预估，标注 `status:"estimated"`，待官方发布校准。

```jsonc
{
  "years": {
    "2026": { "status":"confirmed", "holidays": [
      {"name":"元旦","start":"2026-01-01","end":"2026-01-03","days":3,"workdays":["2026-01-04"]},
      {"name":"春节","start":"2026-02-15","end":"2026-02-23","days":9,"workdays":["2026-02-14","2026-02-28"]},
      {"name":"清明","start":"2026-04-04","end":"2026-04-06","days":3,"workdays":[]},
      {"name":"劳动节","start":"2026-05-01","end":"2026-05-05","days":5,"workdays":["2026-05-09"]},
      {"name":"端午","start":"2026-06-19","end":"2026-06-21","days":3,"workdays":[]},
      {"name":"中秋","start":"2026-09-25","end":"2026-09-27","days":3,"workdays":[]},
      {"name":"国庆","start":"2026-10-01","end":"2026-10-07","days":7,"workdays":["2026-09-20","2026-10-10"]}
    ]},
    "2027": { "status":"estimated", "holidays": [ /* 春节2.5-2.14(9天) 国庆10.1-7(7天) 等，待校准 */ ] }
  }
}
```

### 2.2 每日状态判定（算法，唯一新增逻辑）
任一日期 `d` 的状态：
1. 若在任一节假日的 `[start, end]` 区间内 → **放假**
2. 否则若 `d` 是周六 / 周日 → **周末**（自然休息）
3. 否则若 `d` 命中某节假日的 `workdays`（调休补班）→ **补班**（需上班，除非用户请了该日假）
4. 否则 → **普通工作日**
5. 用户请假覆盖：用户声明"X 日请半天(上午/下午) / 全天" → 该日至少半天**可用**

**可用日** = 放假 OR 周末 OR 用户请假，且不是(补班 且 未请假)。

### 2.3 拼假计算（唯一新增逻辑）
- 输入：用户请假片段列表 `[{date, half:"am"|"pm"|"full"}]` + 当前/参考日期
- 步骤：
  1. 把所有节假日放假日、周末、用户请假日标记为可用（补班日除非已请假才可用）
  2. 以每个请假片段为锚点，向前后双向扫描，扩展连续可用日段
  3. 输出最长连续可用段 = **假期窗口天数**，并列出该段覆盖了哪些（法定节假日 / 周末 / 请假），以及含几个"半天"
- 洁梅说"X月X日请假"，雪花**自动找紧随其后的公共节假日并拼起来**计算，不必等她算好。

### 2.4 按"可用天数"推荐玩法（可达圈档位）
| 窗口天数 | 单程自驾上限 | 玩法范围 | 交通 |
|---|---|---|---|
| 1-2 天 | ≤3h | 珠三角圈（珠海/深圳/惠州/清远/佛山/东莞/中山/江门/肇庆） | 自驾 |
| 3-4 天 | ≤6h | 广东全省 + 邻省短途（潮汕/赣州/湛江/韶关） | 自驾为主 |
| 5-7 天 | 跨省 | 四川/湖南/陕西/福建/广西等（看熊猫 / 顶级博物馆） | 飞+当地租车 或 长自驾 |
| 8 天+ | 远途 | 新疆/云南/东北等 | 飞 |

## 4. 定时任务搜罗逻辑变化（相对 v0.3）

### 4.1 选档搜罗
每周一 07:30 任务：读取 `holidays.json` → 计算"下一个可用窗口天数"（含未来 14 天内是否临近节假日）→ 选 2.4 对应档位 → 全网搜罗该范围高热目的地 → 打分出榜。不再是固定"周末 2 天"和"假期 3 天+"两档，而是按真实窗口天数四档。

### 4.2 全家约束并入打分 / 过滤
- 候选项若触发高海拔三原则"放弃"条件 → 直接过滤（不进榜）
- 自然风光类优先；含顶级博物馆 / 大熊猫的目的地在跨省档加权
- 亲子适配等级继续标注；长途档额外标注"老人友好度"（观光车可达 / 徒步强度）

### 4.3 其余沿用 v0.3
打分模型（口味40+热度20+人少20+新鲜10+天气10）、反馈学习闭环、渠道可信度鉴别、换一批、飞书周一推送、周末 2 天档仍作为"无临近节假日时的默认周更"——**全部沿用 v0.3，不重抄**。
