# 周末雷达 · 完整测试用例文档

> **配套文档**：`周末雷达-开发需求文档(给condex复刻).md`
> **用途**：独立开发者 condex 实现完成后，逐条执行本用例，确认功能与线上版（V1.4.3）对等。
> **判定规则**：每条用例标「通过条件」。任一 P0 用例不通过 = 版本不可发布。
> **环境准备**：
> 1. 部署到 GitHub Pages（或本地静态服务 `python -m http.server` 起 `app/`）。
> 2. 准备一枚 GitHub Personal Token（`repo` 权限），owner=`jiemei919`、repo=`weekend-radar`。
> 3. 浏览器两个环境：Mac（Chrome/Safari，桌面 UA）+ 手机（iOS Safari 添加到桌面 / 安卓 Chrome，移动 UA）。
> 4. 云端数据初始态：`data/wishlist.json` 等为空数组或已知基线（先 `curl` 备份线上基线再测）。

## 十一、自动化冒烟测试（建议 condex 同时提供）

> 原项目用 jsdom 跑无浏览器烟雾测试（`NODE_PATH` 指向托管 node_modules）。condex 应交付等价脚本：
- `smoke-test.js`：页面加载无运行时错误（≥20 断言）。

- `smoke-visited.js`：权威库三档（≥4 断言）。
- `smoke-record-visited.js`：记录去过端到端（添加→过滤→同步→删除，≥6 断言）。
- **通过条件**：以上全部 0 失败，且 `node --check app/*.js` 语法通过。
