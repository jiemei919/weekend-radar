# 「周末雷达」需求文档 v0.3（定稿）

> 给洁梅的周末周边游智能推荐工具 | 撰写：雪花 ❄️ | 2026-07-28 | 状态：全部关键项已确认，开工实做

---

## 1. 要解决的问题（根因）

每周决定"去哪玩"要花大量时间刷小红书、携程、马蜂窝、去哪儿、抖音——信息分散、广告软文多、"网红打卡地"实际人挤人，而且没有任何平台懂"自然风光 + 人少 + chill 商场 + 艺术空间 + 富人区"这种复合口味。**时间花在筛选上，而不是玩上。**

## 2. 实现思路（一句话机制）

雪花每周定时上这 5 类平台搜罗近两周最热的广州周边目的地 → 按"洁梅口味模型"打分排序 → 生成 Top 榜写进 Mac 桌面小工具，同时推送一份摘要到手机飞书；洁梅的每次反馈（想去 / 没兴趣 / 去过打分）回流更新口味模型和渠道可信度，越用越准。

## 3. 产品形态

| 端 | 形态 | 说明 |
|---|---|---|
| Mac 桌面 | 本地网页小工具 | 固定在 Dock，双击即开；右上导航栏放快捷入口（本周最热 / 想去清单 / 去过·点评 / 我的口味 / 设置）。P2 可升级为菜单栏常驻小图标 |
| 手机 | 飞书推送 | 每周一 08:00 飞书推送本周 Top 榜摘要（洁梅飞书已接入，零额外安装），本周去哪玩周一就能定 |
| 数据与学习 | 本地文件 | 候选库、口味模型、反馈记录全部存在 travelling 项目目录，雪花的定时任务负责搜罗 + 打分 + 更新，不依赖任何付费接口 |

## 4. 功能清单（页面 / 入口级）

### 4.1 本周最热榜（首页）
每周 5-8 个目的地卡片，每张卡片包含：
- 名称 + 类型标签（自然 / 人少 / chill商场 / 艺术 / 富人区 / 亲子适配）
- 交通：自驾时长 / 高铁时长
- 热度来源与数据（如"小红书 · 近7天 2.4w 赞"）——可追溯，不是拍脑袋
- 匹配度 %（口味模型打分）
- 一句话推荐理由 + 一句话避坑提示
- 三个操作：⭐想去 / 👎没兴趣（必选原因） / ✅去过了（评分）
- 榜单底部展示"本周已过滤"名单及过滤原因（人太多 / 超出车程 / 近期推过），让过滤逻辑透明

### 4.2 想去清单
点⭐后收藏于此；每条附"最佳前往时段"提示（如"11月芦苇季最佳"）。

### 4.3 去过·点评
去过后打 1-5 星 + 体验标签（人比想象多 / 名不副实 / 比预期好 / 值得再去…）+ 一句话。同时用于：①更新口味模型 ②累计渠道可信度经验。

### 4.4 我的口味
- 五大偏好权重可视化（进度条）
- 学习记录流水（人话解释，如"因为你给盐洲岛打了 5 星，'海边+人少'权重上调"）

### 4.5 设置
出发地（默认广州·番禺区）、假期天数默认档（2 天）、交通方式（自驾优先）、推送开关 / 时间。亲子模式默认开启（铄铄必随行），不可关闭项仅保留标记开关。

## 5. 核心新增逻辑（唯一需要详述的部分）

### 5.1 每周搜罗（定时任务，每周一 07:30 搜罗打分，08:00 推送）
- 渠道：小红书、携程、马蜂窝、去哪儿、抖音（通过全网检索抓取这些平台**近 14 天发布**的高热周边游内容）
- 硬过滤条件（不满足直接不进候选池）：
  - **可达圈按假期天数分档**（见 5.1.1），出发地固定为**广州·番禺区**
  - 近 30 天已上过榜的不重复推荐（例外：热度环比暴涨 ≥3 倍可复推一次）
  - **交通规则：自驾优先**。仅当自驾时间根本来不及、或距离极远（约 800~1000km 以上）时才给出高铁方案

#### 5.1.1 可达圈分档（按本次假期天数）
| 模式 | 单程上限（自驾） | 典型范围样例 |
|---|---|---|
| 周末 2 天（默认） | ≤ 2.5~3h | 珠三角圈：珠海、深圳、惠州、清远、佛山、东莞、中山、江门、肇庆 |
| 假期 3 天+ | ≤ 5~6h | 潮州、汕头、赣州、湛江、阳江、韶关北部等 |

- 工具首页提供"本次假期天数"切换（默认 2 天），切换后榜单按对应可达圈重新过滤排序
- **车程估算以洁梅实际驾驶数据校准**（不是地图默认值）：

| 实测样本 | 洁梅实际用时 |
|---|---|
| 珠海 → 广州（晚间） | ≈ 2h |
| 深圳 → 广州 | ≈ 2.5h |
| 汕头 → 广州 | ≈ 5h |
| 番禺 → 南昌（含服务区休息<1h） | ≈ 9h（8:30 出发 17:30 到） |

  校准规则：地图预估时长 × 洁梅系数（初始按上表拟合，后续每次"去过"反馈中可补充实际车程，持续校准）

#### 5.1.2 亲子规则（铄铄周末必随行）
- 每张目的地卡片**必须标注亲子适配等级**：适合 / 一般 / 不适合
- "不适合儿童"（安全隐患、纯成人场景）的目的地直接过滤，不进榜
- 亲子适配**不改变口味排序**——铄铄和洁梅口味高度重合，主榜依然按洁梅口味打分
- **铄铄彩蛋位**：每期榜单固定保留 1 个铄铄向目的地（游乐场/乐园/科技馆类），单独标注"铄铄专属"，不占主榜 Top 名额、不参与口味打分

### 5.2 匹配打分模型（满分 100，≥70 分才进榜，取 Top 5-8）

| 维度 | 分值 | 规则 |
|---|---|---|
| 口味标签匹配 | 40 | 五大偏好各有权重，初始值：自然 0.9 / 人少 0.9 / chill商场 0.7 / 艺术 0.7 / 富人区 0.6；命中标签按权重加总折算 |
| 平台热度 | 20 | 按点赞/收藏/榜单排名归一化 |
| 人少指数 | 20 | 内容评论中"人多、排队、网红打卡"等负面词密度 vs "小众、清净"正面词密度 |
| 新鲜度 | 10 | 14 天内首次爆火的内容拿满分，旧地新炒减半 |
| 季节/天气适配 | 10 | 结合当周天气预报（台风周海岛类直接 0 分） |

**样例**：惠州盐洲岛 → 标签命中"自然0.9+人少0.9"=36 分，小红书近7天2.4w赞=17 分，评论人少指数=18 分，14天内爆火=10 分，当周晴=8 分 → **89 分，进榜第 1**。

### 5.3 反馈学习规则（核心闭环）

| 反馈动作 | 模型变化 |
|---|---|
| ⭐想去 | 该目的地的标签权重各 +0.05 |
| 👎没兴趣（选原因） | 原因对应标签权重 −0.1；选"太远了"→ 记录一次距离敏感，累计 3 次自动收紧单程上限 0.5h |
| ✅去过，评 5 / 4 星 | 标签权重 +0.15 / +0.08 |
| ✅去过，评 ≤2 星 | 标签权重 −0.2，且该条推荐的**来源平台可信度 −1** |
| 体验标签"名不副实" | 写入渠道鉴别经验库；该平台可信度累计 −3 后，其同类内容必须**≥2 个平台交叉验证**才允许进榜 |

- 权重取值范围 0 ~ 1.2，每次调整写入口味模型文件，并附一句人话解释（可在"我的口味"页查看）。
- 这套规则同时实现两个目标：**懂你的口味** + **鉴别哪些平台的推荐真的靠谱**。

### 5.4 推送
每周一 08:00，飞书推送本周 Top 榜摘要：名称 + 类型 + 番禺自驾时长 + 一句话理由；桌面工具榜单同步更新。

### 5.5 「换一批」机制（洁梅确认新增，2026-07-28）
- 若本期榜单洁梅都觉得不合适，可触发**重新搜罗**：
  - 触发方式：①桌面工具首页点「这批都不合适，换一批」→ 自动复制指令，发给雪花即可；②直接对雪花说"换一批"
- 换一批规则：重新全网搜罗，**排除本期已推目的地**，其余过滤打分规则不变；本期被全量否决这一事实计入学习（本期各目的地主标签权重各 −0.05）
- 时效：收到指令后当次会话内完成新榜单生成与飞书推送

## 6. 其余说明

除上述逻辑外，不引入账号体系、不做多人版、不接第三方付费 API——全部由雪花的定时任务 + 本地文件实现，你的口味数据只存在你自己的电脑上。

## 7. 分期计划

- **P1（本期，确认后开工）**：桌面网页工具 + 每周定时搜罗打分 + 飞书手机推送 + 三类反馈闭环 + 口味模型
- **P2**：Mac 菜单栏常驻图标、坏天气自动改期提醒、想去清单一键生成一日游路线（含吃饭点）

## 8. 验收标准

1. 每周一 08:00 前榜单自动更新，且手机飞书收到推送
1a. 说"换一批"后，当次会话内收到排除旧目的地的新榜单
2. 榜单每条均标注来源平台与热度数据，可追溯
3. 点"没兴趣"并选原因后，"我的口味"页 10 秒内可见对应权重变化记录
4. 去过评分 ≤2 星后，同来源平台的同类内容两周内不再未经交叉验证进榜
5. 超出单程上限的目的地出现次数 = 0
