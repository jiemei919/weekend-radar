## 1. 强偏好（命中 → 推荐命中率高）

### 1.1 自然风光 = 全家第一刚需（你明确"强需求"）
- 海（干净的海、人少的沙滩）："深圳/小径湾海景一流""看海发呆"，"我喜欢人少的沙滩"；反面"汕头水脏远远不如小径湾"。
- 山/湖/峡谷/瀑布/雪山：三清山"风景非常好，能PK的只有黄山"、九寨沟"看水一绝"、德天瀑布、泸沽湖"水非常清"、哈巴雪山"雪山总是美"。
- 非中国 4 条里 3 条是"自然风光太美""荒漠看巨石露营看星星"——跨越国界的底层偏好。

### 1.2 chill 度假 / 躺平 / 温泉 / 度假酒店（活动丰富·可躺平·小孩大人都有项目）
- "很chill，我很喜欢这种氛围，我自己二刷过"；"在酒店躺平一天泡温泉，睡觉，参加酒店活动是很好的"（新兴温泉）；"看海发呆"（小径湾）；"住一晚上…感觉去那里度假，真好"（拈花湾）。
- 印证你要的"省内度假酒店，活动丰富可躺平，有小孩大人项目"——如清远长隆类（儿童乐园 + 徒步 + 温泉可玩整天）。

### 1.3 人少 / 清净 / 非商业化（乐园大IP 例外，见 1.10）
- "龙南天花板，人少，景色还是不错的，关键是人少"；"我喜欢人少的沙滩"。反面："丽江古城里面商店都非常商业化，咖啡贵"→一般。

### 1.4 拍照 = 风景出片 + 小红书强需求（你明确"挺需要的"，只拍风景不拍吃）
- "我喜欢发小红书，所以拍出来漂亮，我也挺需要的"；"其实我内心还是想要拍漂亮照片的"（宽窄巷子）。外滩亮灯"封神"、婺女洲打铁花"很震撼"、泸沽湖女神峰"拍照太漂亮了"。
- **限定**：你"几乎不拍吃的，就是风景"——拍照维度 = 风景/建筑/夜景出片，**不是美食拍照**。推荐时突出"出片点"。

### 1.5 博物馆/知名馆 + 有特色历史建筑
- "湖南省博物馆必须夯"（长沙，强烈）；海昏侯"很多大金子"；反面：杜甫草堂"其实没什么意思"、普通故居"没意思"。
- 有特色建筑（土楼"值得去一次"、徽派"比丽江好"、园林"做的很好"）偏好；红色旅游"去一次即可"（中性偏低）。

### 1.6 寺庙 / 拜拜
- "对寺庙我都是有兴趣去拜拜的"（明确）；藏族寺庙、灵山大佛、六祖真身都给好评。

### 1.7 亲子 = 照顾小朋友情绪 + 要有能玩的（铄铄，10岁男孩）
- **核心重定义（18:53）**：不是"小孩不累就行"，而是**照顾小朋友的情绪，要有他能玩的项目**——这是亲子维度的硬指标。
- **熊猫（强！）**："现在小孩非常喜欢熊猫，有熊猫为特色的地方还是要安排熊猫的行程"（成都基地）。
- 小孩能玩：摸鱼/捏泥巴/乐园(120块通玩)/看恐龙蛋/看海龟/漂流/玻璃桥/动物乐园。
- 老少皆宜不累：名山"爬起来不累的"（衡山）、缆车（峨眉山、玉龙雪山）。

### 1.8 漂亮型新购物村 / 商业体（可推）
- "新的购物村，修得漂亮的（像国外的，比如东莞华润购物村、太古里啥的）可以推荐，我去逛逛还是不错的"。
- 区别于"普通奥莱"——奥莱你"时不时自己就会去"，不必强推；**新的、修得漂亮（像国外/太古里类）的商业体**值得推（兼具逛 + 风景出片）。

### 1.9 动物园（有特点的动物园）= 强偏好（18:53 新增）
- 你原话："动物园，其实挺喜欢去玩的，特别是有特点的动物园"。
- **长隆类动物乐园**是你很喜欢的大类——"我还是很喜欢这种动物乐园"。珠海长隆/长隆水上乐园"几乎每年必刷一次"。

## 3. 强排斥（命中 → 拦截）
1. **老/假/萧条/无人维护的景区**——"大避雷，还不如海珠湖，五星太假了，景区很老很萧条"（肇庆）。
2. **脏海 / 差沙滩**——"水脏"（汕头）、"海脏，没有沙滩，严重避雷"（广州某海滩）。
3. **过度商业化古城**——"里面商店都非常商业化"（丽江）→一般。
4. **人多 + 物价贵**——迪士尼"人太多物价太贵，如果人不多再去玩是可以的"（人少可救）。**例外**：大IP乐园未去过 → 豁免"人多"，但"物价贵"仍计入。
5. **无聊 / 没看点 / 纯购物无特色**——"超级无聊"（厦门除鼓浪屿）、"没什么意思"（杜甫草堂）。
6. **贵而不值 / 门票贵无亮点**——"船票也太贵了，去过一次肯定不去了"；阳江"海鲜特别坑，物价无比的贵"。
7. **停车难**——"难停车"（避雷点之一）。
8. **已去过且腻/去太多次**——"去得有点腻了""去太多次了"→默认不推（长隆类除外，见 1.9/1.10）。

## 4. 特殊规则（精准版）
- **贵州 = 清单屏蔽 + 新景点开放**：
  - 避开（从小去过太多次）：**黄果树、龙宫、花溪、天河潭、苗寨、侗寨、梵净山、小七孔、赤水瀑布、杉木河漂流、遵义、红枫湖**。
  - 新的可推：如**茂兰**，"还挺好的"——不在避开清单里的新地方/新玩法可推荐。
- **家附近（番禺/广州）= 默认开放**：你"尽量都列出来了"，**没列出来的附近好玩的也可以推**。
- **非中国 = 近国优先 + 详评价格时间**：出国花钱多、花时间多，"要非常详细的思考才行"，**不随便推**；但"也考虑去国外的"，**先从广州附近的国家开始推荐**（东南亚等近邻）；推前必须附价格估算、时间成本、适合全家程度。
- **长隆实例降温（18:53）**：珠海长隆/长隆水上乐园"几乎每年必刷"但"珠海长隆这几年觉得就一般了" → **动物乐园类别强推，珠海长隆具体实例降权**（作为复访顺位靠后，不主动首推，但你提了就配合）。

## 5. 推荐逻辑
**目的地客观质量（别人说好 + 少人避坑）∩ 全家偏好 = 推荐集。**
- 别人说好、人少，但不符合你家偏好（纯购物古城、太累不适合老人小孩、老景区）→ 不推。
- 符合你家偏好，但网上口碑差/多人避雷 → 不推。
- 两者都过 → 推，并按匹配维度打标签（如"自然风光 + 人少 + 动物园特色 + 出片"）。
- **大IP乐园豁免**：未去过的大IP乐园，即便人多也进入推荐（一次性体验），但标"人多·建议错峰/买快速通"。

## 6. 自学习器（长期进化 —— 你明确要求"持续学习进化偏好"）
- **真值源文件**：`data/taste-profile.json`（机器可读，雪花维护）。本画像 doc 是它的"人话版"，两者同源。
- **初始化**：三表 161 条评论 = 基线语料；v1→v1.1→v1.2 的每次洁梅反馈都记入 `changelog` + 调整对应维度 `weight` / 追加 `evidence`。
- **反馈闭环（每次洁梅给反馈自动执行）**：
  1. 收到反馈（感兴趣 / 不感兴趣 / 去过评价 / 有没有去 / 新偏好）→ 追加 `feedback-log.json`。
  2. 按反馈类型更新 `taste-profile.json`：调维度权重 + 加证据引用 + 写 `changelog`（日期/改了啥/原因，人话）。
  3. 同步更新本画像 doc（人话版）。
  4. 若涉及已去过去重 → 回写 `visited.json`（三档）。
- **偏好非静态**：你明确"偏好也不是一成不变的，需要不断修正"。所以权重会随新反馈浮动（例如"户外运动"从机制升级为强维度，就是一次进化）。
- **未来 app 接入**：偏好匹配层读取 `taste-profile.json` 对候选地打分（命中维度加权求和 → 推荐分 + 标签），低于阈值的拦截不推。
- **界面呈现原则（08-04 你明确要求）**：打分和标签**只在内部用于过滤/排序，绝不展示给你看**。卡片只呈现「推荐地去哪 + 为什么好玩/为什么适合你们全家」（自然语言理由）。你的目标原话："推荐的我都觉得好玩且愿意去"。匹配层要做的是高精准，不是把算分过程甩给你。
